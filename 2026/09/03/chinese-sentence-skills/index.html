小学语文常考句子技巧与练习

发表于 2026-09-03 分类于 学习 ， 语文 ， 小学 置顶 精品
阅读次数： 0 本文字数： 6.4k 阅读时长 ≈ 23 分钟

摘要

  • 小学语文句子题，本质是 抓住主干、理清人称、改标点、换语气，掌握方法比刷题更重要。
  • 本文覆盖 扩句 / 缩句、直述 ↔ 转述、陈述 ↔ 反问、肯定 ↔ 双重否定、提示语标点、把字句 ↔ 被字句、修改病句、比喻 / 拟人。
  • 每类按「定义 → 方法 → 口诀 → 例题」组织，例题均给出参考答案，方便自学和家长辅导。
  • 做题时始终抓住一条底线：句意不能变。

一、怎么查这篇笔记

我想练… 去哪一节
把短句写具体 二、扩句训练
找出句子主干 三、缩句训练
引号里的话改成转述 四、直述句改为转述句
转述改回原话 五、转述句改为直述句
陈述句加强语气 六、陈述句改反问句
反问句改回陈述 七、反问句改陈述句
双重否定强调肯定 八、肯定句与双重否定句互换
说话人提示语标点 九、提示语专项
把 / 被互换 十、把字句与被字句互换
找病因改病句 十一、修改病句
改写比喻、拟人 十二、改写比喻句 / 十三、改写拟人句

核心口诀：

扩句加枝叶，缩句留主干。
直转改人称，反问肯否换。
把被换位置，病句八法看。

二、扩句训练

2.1 定义

扩句就是在句子主要成分的前后加上适当的修饰词，让句子更加完整、具体、生动。可以记成：主干深枝加叶。

2.2 方法

方法 做法 例子
扩名词 在名词前加形容词、数量词 小狗看着骨头 → 一只胖乎乎的小狗看着一根粗大的骨头
扩动词 在动词前加副词等修饰语 他跑 → 他飞快地跑
扩地点 在人物或事物后补地点（在哪里 / 从哪里） 他跑 → 他在操场上跑；红旗飘扬 → 红旗在天安门广场上飘扬
加修饰 适当用比喻、拟人等修辞 雨点落下来 → 雨点像豆子一样噼里啪啦地落下来；月亮升起 → 月亮害羞地从天边升起

总括： 名词前加形容词，动词前加副词，人事后加地点（在哪里 / 从哪里），需要时再加比喻、拟人。

2.3 原则

  1. 至少扩两处（题目另有要求除外）。

  2. 简洁，不堆砌。

  3. 不改变原句意思。

2.4 练题

  1. 论论做操。

    • 扩句：活泼可爱的论论认真地做操。
    • 说明：扩名词「活泼可爱的」+ 扩动词「认真地」。

  2. 红旗飘扬。

    • 扩句：鲜艳的红旗在天安门广场上飘扬。
    • 说明：扩名词「鲜艳的」+ 扩地点「在天安门广场上」。

  3. 雨点落下来。

    • 扩句：豆大的雨点哗哗地落下来。
    • 说明：扩名词「豆大的」+ 扩动词「哗哗地」。

  4. 月亮升起。

    • 扩句：圆圆的月亮从天边缓缓升起。
    • 说明：扩名词「圆圆的」+ 扩地点「从天边」+ 扩动词「缓缓」。

三、缩句训练

3.1 定义

缩句就是把「枝繁叶茂」的长句子，提炼为只留主干的短句子，且不改变原句主要意思。可以记成：保留主干，去掉枝叶。

3.2 方法：四删除、四保留，抓主干

四删除：

  1. 「的、地、得」修饰成分要删（「的、地」前的修饰语，「得」后的补语）。

  2. 数量词、数字一般删掉。

  3. 时间、地点、条件等状语整段删掉（如「在……」「向……」）。

  4. 指示代词「这、那」要删掉。

四保留：

  1. 「着、了、过」要保留。

  2. 「不、无、没有」等否定词要保留。

  3. 「啊、吗、呀、呢」等语气词要保留。

  4. 「把」「被」要保留。

抓主干： 谁 + 干什么。

3.3 例题

  1. 那可爱的小猴子在公园的假山上开心得跳来跳去。

    • 缩句：小猴子跳来跳去。
    • 说明：删「那」「可爱的」（的前修饰）、删地点「在公园的假山上」、删「开心得」（得后补语）；主干「小猴子跳来跳去」。

  2. 广场上千万盏灯静静地照耀着天安门广场周围的宏伟建筑。

    • 缩句：灯照耀着建筑。
    • 说明：删地点「广场上」、删数量「千万盏」、删「静静地」、删「天安门广场周围的」「宏伟」；保留「着」；主干「灯照耀着建筑」。

  3. 金色的阳光照遍了美丽的田野。

    • 缩句：阳光照遍了田野。
    • 说明：删「金色的」「美丽的」；保留「了」；主干「阳光照遍了田野」。

  4. 小兴安岭是一座美丽的大花园，也是一座巨大的宝库。

    • 缩句：小兴安岭是花园，也是宝库。
    • 说明：删数量「一座」、删「美丽的」「巨大的」；「大」也是修饰「花园」的定语，一并删掉；并列判断句两边都只留主干。

四、直述句改为转述句

4.1 定义

  • 直述句（直接引语）： 直接引用别人的话。

  • 转述句（间接引语）： 把别人的话转述出来。

注意： 只改双引号中的内容；双引号外的提示语一般不变；句意不变。

4.2 方法

① 改标点

  • 冒号（：）改成逗号（，）

  • 去掉双引号（“”）

② 改人称（难点）

原人称 怎么改 例子
我（们） 改成他 / 她（们） 小强说：“我一定要坚持每天跑步。” → 小强说，他一定要坚持每天跑步。
你（们） 改成听话人的名字；不知道名字时可改成「我（们）」 外婆对小宁说：“我今天给你做了鱼香肉丝。” → 外婆对小宁说，她今天给小宁做了鱼香肉丝。

人称速查：

  • 第一人称：我、我们

  • 第二人称：你、你们

  • 第三人称：他、她、它、他们、她们、它们，以及具体名字、称呼

③ 删改词语

  • 「啊、呀、吧、吗」等语气词一般删掉。

  • 「这」常改「那」，「来」常改「去」（要结合说话双方的位置判断）。

  • 反问句要改为陈述句。

④ 祈使句

语气词前常加「让」，去掉「吧」「！」，改成句号。

⑤ 提醒

冒号前面的提示语一般不能乱改。

4.3 例题

  1. 说话时的语气词要删去。

    • 原句：裁缝说：“我和别的武峰不一样，我是个性子最慢的裁缝啊。”
    • 转述：裁缝说，他和别的武峰不一样，他是个性子最慢的裁缝。
    • 说明：「：」改「，」，去掉引号；「我」→「他」；删语气词「啊」。

  2. 转述内容中的第三人称要看具体指谁；一般不改。若同时出现两个「他」造成指代不明，再改。

    • 原句：老师对小明说：“这件事情，你冤枉了小红。”
    • 转述：老师对小明说，这件事情，他冤枉了小红。
    • 说明：「你」指小明，改为「他」；第三人称「小红」不变。

  3. 指示代词的变化（这 → 那；来 / 去看位置）。

    • 原句：叔叔在信里对我说：“有时间我一定到你那儿玩。”
    • 转述：叔叔在信里对我说，有时间他一定到我这儿玩。
    • 说明：「我」→「他」；「你那儿」从「我」的角度看改为「我这儿」。

  4. 趋向动词（来 ↔ 去）要结合双方位置。

    • 原句：妈妈对我说：“中午我去给你送饭。”
    • 转述：妈妈对我说，中午她来给我送饭。
    • 说明：「我」→「她」；「你」→「我」；妈妈朝「我」这边送，故「去」改「来」。

  5. 反问改为陈述。

    • 原句：小丽说：“我怎么舍得让小白变成流浪狗呢！”
    • 转述：小丽说，她舍不得让小白变成流浪狗。
    • 说明：「我」→「她」；反问「怎么舍得……呢」改为陈述「舍不得」；删「呢」「！」。

  6. 祈使句加「让」，去掉「吧」「！」。

    • 原句：奶奶说：“月亮是每个人的，它并没走，你们去找它。”
    • 转述：奶奶说，月亮是每个人的，它并没走，让我们去找它。
    • 说明：「你们」改为「我们」（听话一方）；祈使语气前加「让」。

  7. 原句：老师对我说：“把你的作业本拿给我看看。”

    • 转述：老师对我说，把我的作业本拿给她看看。
    • 说明：「你」→「我」；「我」（老师）→「她」；「把」保留。

  8. 原句：小王说：“老师，是我不对，您批评我吧。”

    • 转述：小王对老师说，是他不对，让老师批评他。
    • 说明：称呼「老师」并入提示语；「我」→「他」；「您」→「老师」；祈使加「让」，删「吧」。

  9. 原句：诸葛亮对鲁肃说：“你借给我二十条船，我自有妙用。”

    • 转述：诸葛亮对鲁肃说，请鲁肃借给他二十条船，他自有妙用。
    • 说明：「你」→「鲁肃」；「我」→「他」；祈使语气加「请」。

五、转述句改为直述句

5.1 定义

把别人说的话，从间接引用改回直接说的话。

5.2 方法

  1. 添加双引号，必要时补适当语气词。

  2. 把逗号改成冒号。

  3. 把第三人称「他 / 她」等改回第一人称「我、我们」；听话对象常改回「你、你们」。

5.3 例题

  1. 小明生气地说，这样的问题不会难倒他们。

    • 改：小明生气地说：“这样的问题怎么能把我们难倒呢！”
    • 说明：，改：，加引号；「他们」→「我们」；可加反问语气加强生气语气。

  2. 小红对小丽说，她连老师都不怕，不会怕小丽。

    • 改：小红对小丽说：“我连老师都不怕，还会怕你吗？”
    • 说明：「她」→「我」；「小丽」→「你」；后半可改反问，语气更贴切。

  3. 小明对小芳说，小芳的书包非常漂亮，他非常喜欢。

    • 改：小明对小芳说：“你的书包非常漂亮，我非常喜欢。”
    • 说明：「小芳」→「你」；「他」→「我」。

六、陈述句改反问句

6.1 定义

  • 陈述句： 用陈述语气说明事实，句末用句号。

  • 反问句： 用疑问形式表达肯定观点，答案就在问句中，用来加强语气，句末用问号。

6.2 方法

两加：

  1. 加反问词：难道、怎、怎么、怎能等。

  2. 加语气词：吗、呢等。

两改：

  1. 肯定词（是、能、会、该等）改成否定词（不是、不能、不会、不该等），或否定改肯定（肯改否 / 否改肯）。

  2. 句号改问号。

改完后检查：通顺吗？意思和原句一致吗？

6.3 口诀

  • 陈述句 → 反问句：有「不」去掉，没「不」加「不」；加反问词；句号变问号。

  • 反问句 → 陈述句：有「不」去掉，没「不」加「不」；去掉疑问词；问号变句号。

6.4 例题

  1. 美丽的草原让人陶醉。

    • 改：美丽的草原怎能不让人陶醉？
    • 说明：加反问词「怎能」；原句无「不」，故加「不」；。改？。

  2. 电线上停着的几个小黑点，是伶俐可爱的小燕子。

    • 改：电线上停着的几个小黑点，难道不是伶俐可爱的小燕子吗？
    • 说明：加「难道……吗」；「是」改「不是」；。改？。

  3. 我们作为华夏儿女应该好好学习，长大后报效祖国。

    • 改：我们作为华夏儿女，难道不应该好好学习，长大后报效祖国吗？
    • 说明：加「难道……吗」；「应该」改「不应该」；。改？。

七、反问句改陈述句

7.1 作用与特点

反问用来加强语气，使感情更强烈。常见标志：

  1. 句末有「？」或「！」。

  2. 句中有「难道、怎能」等。

  3. 答案就在句中。

7.2 方法

两删：

  1. 删去反问词「难道、怎么能」等。

  2. 删去语气词「吗、呢」等。

两改：

  1. 否定改肯定，或肯定改否定。

  2. 问号改句号。

一调整： 适当增减词语，使句子通顺，句意不变。

7.3 例题

  1. 难道钱塘江大潮不是天下奇观吗？

    • 改：钱塘江大潮是天下奇观。
    • 说明：删「难道」「吗」；「不是」改「是」；？改。。

  2. 面对急需帮助的人们，我们怎么能袖手旁观呢？

    • 改：面对急需帮助的人们，我们不能袖手旁观。
    • 说明：删「怎么」「呢」；肯定「能」改否定「不能」；？改。。

  3. 在公共场所怎么能乱丢垃圾呢？清洁工人打扫卫生难道不辛苦吗？

    • 改：在公共场所不能乱丢垃圾。清洁工人打扫卫生很辛苦。
    • 说明：前句删「怎么」「呢」，「能」→「不能」；后句删「难道」「吗」，「不辛苦」→「很辛苦」。

八、肯定句与双重否定句互换

8.1 定义

  • 肯定句： 说明或肯定某一事物或事实。例：他是位医生。

  • 双重否定句： 句中有两个否定词，用「否定 + 否定」表达肯定。例：我们不应当不参加集体活动。

8.2 肯定句改为双重否定句

  1. 一找： 找出关键词，选择恰当的双重否定格式。

  2. 二换： 替换原句中「要、能、应该、都、只得、一定、必须」等词语。

  3. 三删： 删去「很、非常、十分、分外、更加」等程度副词（避免语气叠床架屋）。

常见对应：

情况 原词 / 意思 常改成
表示判断 是、了 不可能不……；谁也不能否认……
表示非常肯定 必须、一定要 非……不可；不能不
表示不情愿、不得已 只好、只能、只得 不得不
表示全部 全都、全部 无不；没有（一个）不
表示推测 会、可能、能、应该 不可能不；不会不
表示存在 有 不是没有

例：

  1. 周总理是我们的好总理。

    • 改：谁也不能否认周总理是我们的好总理。
    • 说明：表示判断，用「谁也不能否认……」。

  2. 星期天，我必须去图书馆看书。

    • 改：星期天，我非去图书馆看书不可。
    • 说明：表示非常肯定，「必须」→「非……不可」。

  3. 今天我没带雨具，只能淋雨回家了。

    • 改：今天我没带雨具，不得不淋雨回家了。
    • 说明：表示不得已，「只能」→「不得不」。

  4. 每个小孩子都喜欢小动物。

    • 改：没有小孩子不喜欢小动物。
    • 说明：表示全部，「都」→「没有……不」。

  5. 妈妈会喜欢这束漂亮的鲜花的。

    • 改：妈妈不会不喜欢这束漂亮的鲜花的。
    • 说明：表示推测，「会」→「不会不」。

  6. 他这样做虽然过分了点，但还是有道理的。

    • 改：他这样做虽然过分了点，但不是没有道理的。
    • 说明：表示存在，「有」→「不是没有」。

8.3 双重否定句改肯定句

去掉双重否定词，再按意思换成肯定词语，如「只好、必须、一定、都、全」等。

8.4 例题

  1. 所有人都惧怕他的威严。

    • 改：没有一个人不惧怕他的威严。
    • 说明：表示全部，「所有人都」→「没有一个人不」。

  2. 我只得把他们的母亲送进了疯人院。

    • 改：我不得不把他们的母亲送进了疯人院。
    • 说明：表示不得已，「只得」→「不得不」。

  3. 我们得保证那东西完好无损。

    • 改：我们非保证那东西完好无损不可。
    • 说明：表示必须，「得」→「非……不可」。

九、提示语专项（不同位置的标点）

9.1 定义

对话中，说明「谁在说话」以及说话时的神态、动作、心理的语句，叫作提示语。提示语可以在前、在后、在中间。

例：

  1. 小男孩摆弄了很久很久，说：“一切准备停当。”

  2. “一定会回来！”男孩肯定地说。

  3. “是的。”小男孩站起来，鞠了个躬，“请让我走吧！”

9.2 口诀

  • 提示语在前，冒号引号紧相连；

  • 提示语在后，后面画个小圆圈；

  • 提示语在中间，后面画个小斜杠（逗号）。

9.3 解题步骤

  1. 一找： 找提示语，找说话内容。

  2. 二戴： 给说话内容戴「耳机」（加双引号）。

  3. 三标： 给提示语标标点（双引号与其他标点通常同占一格）。

9.4 例题

  1. 老屋问：“小蜘蛛，你吃饱了吗？”

    • 提示语在后：“小蜘蛛，你吃饱了吗？”老屋问。
    • 提示语在中间：“小蜘蛛，”老屋问，“你吃饱了吗？”
    • 说明：提示语后用句号；提示语在中间时前后说话内容都加引号，提示语后用逗号。

  2. “猜猜看，我给你买了什么？”妈妈神秘地说。

    • 提示语在前：妈妈神秘地说：“猜猜看，我给你买了什么？”
    • 提示语在中间：“猜猜看，”妈妈神秘地说，“我给你买了什么？”
    • 说明：提示语在前用冒号+引号；中间断开处用逗号，后半段另起引号。

  3. “奶奶！”小女孩叫起来，“啊！请把我带走吧！”

    • 提示语在后：“奶奶！啊！请把我带走吧！”小女孩叫起来。
    • 提示语在前：小女孩叫起来：“奶奶！啊！请把我带走吧！”
    • 说明：提示语挪到后/前时，两段说话内容合并；后用句号，前用冒号。

十、把字句与被字句互换

10.1 含义

  • 把字句： 主动者 + 把 + 被动者 + 动作（谁把什么怎么样）

  • 被字句： 被动者 + 被 + 主动者 + 动作（什么被谁怎么样）

例：丽丽把苹果吃了。 → 苹果被丽丽吃了。

10.2 方法

  1. 找出主动者和被动者。

  2. 「把」和「被」互换。

  3. 主动者与被动者变换位置。

  4. 动作不变。

10.3 例题

  1. 一座堤坝被凶猛的水冲破了。（改成把字句）

    • 改：凶猛的水把一座堤坝冲破了。
    • 说明：被动者「堤坝」与主动者「水」换位；「被」改「把」；动作「冲破了」不变。

  2. 森林爷爷战胜了妖魔。（改成被字句）

    • 改：妖魔被森林爷爷战胜了。
    • 说明：主动者「森林爷爷」与被动者「妖魔」换位；加「被」；动作不变。

  3. 陈医生看好了孩子的病。（改为把字句和被字句）

    • 把字句：陈医生把孩子的病看好了。
    • 被字句：孩子的病被陈医生看好了。
    • 说明：主动者「陈医生」，被动者「孩子的病」；把字句强调处置，被字句强调承受。

十一、修改病句

11.1 修改方法：一读，二找，三改，四查

  1. 读： 读通句子，弄清原意。

  2. 找： 确定病症和病因。

  3. 改： 对症下药，用增、删、调、换改正。

  4. 查： 重读一两遍，确认既改对又保持原意。

常见修改符号：对调、移动、删除、改正、增补（考试时按老师教的符号书写）。

11.2 修改口诀

修改病句八方法：

  1. 一看成分缺不缺（成分残缺）

  2. 二看搭配当不当（搭配不当）

  3. 三看用词对不对（用词不当）

  4. 四看意思重复否（重复累赘）

  5. 五看句子矛盾否（前后矛盾）

  6. 六看指代明确否（指代不明）

  7. 七看词序颠倒否（词序颠倒）

  8. 八看逻辑合理否（不合逻辑）

11.3 病句常见类型

（一）错别字

句子中含有错别字

  • 小李老师以经走了。 → 小李老师已经走了。

  • 果园里种满了一颗颗果树。 → 果园里种满了一棵棵果树。

（二）成分残缺

完整句子通常有主语、谓语、宾语等必要成分。

  • 放学了，都向校门走去。（缺主语：谁向校门走去？同学们）

  • 我们应该从小培养诚实守信。（缺宾语：培养什么？的品德）

  • 春天到了，路两旁花草树木。（缺谓语：花草树木怎么了？发芽了）

（三）用词不当

范围、轻重、褒贬、近义词、关联词容易用错。

  • 李叔叔和爸爸热忱地握手。（「热忱」宜改为「热情」一类更贴切的词，或按语境调整）

  • 我们一定要紧紧勾结，互相帮助。（褒贬不当，「勾结」 改为 「团结」）

  • 只要坚持学习，才能取得优良成绩。（关联词不当，应改为「只有……才……」）

（四）搭配不当

在句中某些词语在意义上不能相互搭配或者是搭配起来不合事理，违反了语言的习惯，造成了病句。

  • 妈妈穿上棉衣和围巾出门了。（「穿」与「围巾」搭配不当，棉衣与围巾分开说，应该是 「围上」）

  • 我们有一双聪明的手，什么做不出来呢？（「聪明」和「手」搭配不当，应该是 「能干」）

  • 随地吐痰的人是一种不文明的行为。（「的人」与「行为」搭配不当）

（五）归类不当

列举的事物不是同一类。

  • 我的文具盒里有铅笔、橡皮、直尺、巧克力等文具。（「巧克力」不属于文具）

  • 秋天到了，地里的庄稼和高粱成熟了。（高粱属于庄稼，宜删「和高粱」或改为同一类的，如 「麦子」）

（六）重复累赘

句中所用词语重复，显得啰啰嗦嗦。

  • 他经常回想过去的往事。（「过去的」与「往」重复）

  • 我忍不住不禁笑了起来。（「忍不住」与「不禁」重复）

  • 阅读分享课上，我总是首先第一个发言。（「首先」与「第一个」重复）

（七）词序颠倒

在一般情况下，一句话里面的词序是固定的，词序变了，颠倒了位置，句子的意思就会发生变化，甚至造成病句。

  • 班会上，大家对批评并提出许多问题。（应先提出问题，再讨论 / 批评，按逻辑调整）

  • 历史博物馆展出了两千多年前的新出土的一批文物。（「新出土的」与「两千多年前的」顺序颠倒）

（八）前后矛盾

前后表达意思自相矛盾，造成语义不明。

  • 广场上到处是五颜六色的红旗。（「五颜六色」与「红」矛盾）

  • 队会上，队员基本全部发表了意见。（「基本」与「全部」矛盾）

  • 造纸术是我国的四大发明。（应改为「造纸术是我国的四大发明之一」）

十二、改写比喻句

12.1 含义

比喻就是打比方：用一事物比方另一事物，使句子更生动、具体、形象。

12.2 比喻的三要素

  1. 本体： 被比方的事物

  2. 喻体： 用来作比方的事物

  3. 比喻词： 表示比喻关系的词

例：妹妹的脸儿，红得像一个熟透的苹果。

  • 本体：妹妹的脸儿

  • 比喻词：像

  • 喻体：熟透的苹果

常见比喻词：像、好像、若、似、似的、如、犹如、仿佛、如同、一样、成、是……

12.3 步骤

  1. 明确本体

  2. 找出特点

  3. 联想喻体

  4. 修饰喻体

12.4 例题

  1. 中秋节晚上，一轮明月悬挂在空中。

    • 改：中秋节晚上，一轮明月悬挂在空中，像一面美丽的玉盘。
    • 说明：本体「明月」；比喻词「像」；喻体「美丽的玉盘」（圆、亮）。

  2. 一棵高大的橡树挺立在路旁。

    • 改：一棵高大的橡树像草原的卫兵，挺立在路旁。
    • 说明：本体「橡树」；比喻词「像」；喻体「草原的卫兵」（高大、挺立）。

  3. 天空中挂着火红的太阳。

    • 改：天空中挂着火红的太阳，宛如一个大火球。
    • 说明：本体「太阳」；比喻词「宛如」；喻体「大火球」（红、圆、热）。

  4. 云朵飘浮在空中。

    • 改：云朵像洁白的羽毛，飘浮在空中。
    • 说明：本体「云朵」；比喻词「像」；喻体「洁白的羽毛」（轻、白、飘）。

十三、改写拟人句

13.1 含义

拟人：把事物当作人来写，赋予事物人的行为、语言和思想感情。

例：夜空中的星星，在不停地眨着眼睛。

13.2 方法

方法 可加内容 例子
加声音 唱歌、说话、吵架、讨论…… 小鸟在枝头鸣叫 → 小鸟在枝头上唱着动听的歌
加动作 跳舞、奔跑、散步、低头、弯腰、笑…… 秋天到了，稻子熟了，高粱红了 → 秋天到了，稻子笑弯了腰，高粱涨红了脸
加颜色 / 表情 穿衣服、羞红了脸…… 桃花是粉色的 → 桃花穿上漂亮的粉裙子

13.3 口诀

找声音，会说话；找动作，会跳舞；能哭会笑加表情；外观变化穿衣服。不要出现比喻词，原句意思不能变，人物特征要明显。

13.4 步骤

  1. 找到原句动作（动词）。

  2. 把动作换成人的动作或状态。

13.5 例题

  1. 小花在秋风中摇来摇去。

    • 改：小花在秋风中笑弯了腰。
    • 说明：加动作 / 表情，「摇来摇去」换成「笑弯了腰」。

  2. 月亮被黑云遮住了。

    • 改：月亮美丽的脸庞被黑云遮住了。
    • 说明：加表情 / 外貌，把月亮写成有「脸庞」。

  3. 路口的红绿灯正在交替地闪烁着。

    • 改：路口的红绿灯正在忙碌地工作着。
    • 说明：加动作，「闪烁」换成「忙碌地工作」。

  4. 风儿吹向大地。

    • 改：风儿唱着欢乐的歌吹向大地。
    • 说明：加声音，「唱着欢乐的歌」。

  5. 雨滴淋在树上，树叶沙沙作响。

    • 改：雨滴淋在树上，树叶发出了沙沙的笑声。
    • 说明：加声音 / 表情，「沙沙作响」写成「沙沙的笑声」。

十四、复习清单

做题前可快速自检：

  1. 扩句：扩了几处？原意变了吗？

  2. 缩句：主干是「谁 + 干什么」吗？该留的「着了过 / 不 / 把被」留了吗？

  3. 直转互改：人称、标点、「这那来去」、反问与祈使都处理了吗？

  4. 反问互改：「不」加对了吗？问号 / 句号换对了吗？

  5. 双重否定：两个否定词表达的是更强的肯定吗？

  6. 提示语：前 / 中 / 后的标点口诀对上了吗？

  7. 把被：主动者、被动者位置换对了吗？

  8. 病句：八种病因里是哪一种？改完原意还在吗？

  9. 比喻 / 拟人：本体清楚吗？拟人有没有误写成带比喻词的句子？

把方法练熟后，再限时做一套综合练习，比机械抄写更有效。
