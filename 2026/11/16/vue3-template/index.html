SFC 里的 template

单文件组件通常三块：

要点：

  • <template> 是组件的声明式视图；编译后变成渲染函数

  • <script setup> 顶层绑定会自动暴露给模板，不必 return

  • 模板必须是合法 HTML 结构；根节点在 Vue 3 可以有多个（片段）

  • 模板里写的是表达式，不是任意语句（见下文）

单独的 <template> 标签（不带组件）也可作不可见包装：配合 v-if / v-for / v-slot 包一组节点，本身不渲染成 DOM 元素。

文本插值与 v-html

双大括号

  • 按文本插入，会转义 HTML

  • msg 变化时自动更新

v-text / v-html

v-html 按 HTML 插入，不解析其中的 Vue 模板语法。只用于可信内容；不要把用户输入直接塞进 v-html（XSS）。

scoped CSS 不会作用到 v-html 插入的内容。

表达式规则

模板绑定里可以用完整 JS 表达式，但每处绑定只能是单一表达式（能写在 return 后面的那种）：

  • 可调用组件里暴露的方法；方法在每次更新时可能被调用，不要有副作用（改数据、发请求）

  • 只能访问有限全局（如 Math、Date）；自定义全局需挂到 app.config.globalProperties

指令解剖

形态 示例 含义
无参数 v-if="seen" 表达式为真才渲染
有参数 v-bind:href="url" 把 url 绑到 href
动态参数 v-bind:[attrName]="val" 参数名运行时决定
修饰符 @submit.prevent 提交时 preventDefault
简写 :href / @click / #header v-bind / v-on / v-slot

动态参数的值须是字符串或 null（null 表示移除绑定）。复杂表达式建议放到计算属性。DOM 内嵌模板里属性名会被转成小写，动态参数慎用驼峰；SFC 无此限制。

v-on：事件

简写 @。

基础

  • 普通元素：听原生 DOM 事件

  • 组件：听子组件 emit 的自定义事件（Vue 3 无需 .native）

修饰符速查

可链式组合：@click.stop.prevent。

修饰符 作用
.stop stopPropagation
.prevent preventDefault
.capture 捕获阶段监听
.self 事件从本元素发出才触发（子元素冒泡上来的不触发）
.once 最多触发一次
.passive { passive: true }（滚动性能）
.left / .right / .middle 鼠标按键
.enter / .esc / .tab / .space / .up / .down / .left / .right 等 按键别名
.ctrl / .alt / .shift / .meta 系统修饰键
.exact 精确组合（有多余修饰键则不触发）

系统修饰键也可配在 keyup：@keyup.ctrl="onCtrl"。注意 keyup 时若先松修饰键，可能检测不到组合，按需改用 keydown。

条件渲染

v-if / v-else-if / v-else

  • 条件为假时不渲染（可销毁 / 重建内部状态）

  • 懒：初始为假时，内部一开始不会渲染

v-show

v-if v-show
隐藏方式 不渲染 / 销毁 display: none
初始成本 假时更低 总是渲染
切换成本 更高 更低
适用 Cond 很少变 频繁切换

v-else 不能接在 v-show 后面。

同一元素上不要同时写 v-if 与 v-for。Vue 3 中 v-if 优先级更高，往往拿不到 v-for 的作用域变量。需要时先用 computed 过滤列表，或把 v-if 放到内层 / 外层 <template>。
